# Stella Sora - Data & Assets

Recursos extraídos y organizados del juego **Stella Sora** (Yostar Games).

## Contenido del Repositorio

- **`01_Cinematicas_Videos/`**: Cinemáticas de prólogo, finales de capítulos, intros y animaciones de gacha en formato `.mp4` con subtítulos `.srt`.
- **`02_Audios/`**: Audios del juego convertidos a formato `.wav` estándar (voces japonesas de personajes, música de fondo / BGM y efectos sonoros).
- **`03_Modelos_Live2D/`**: 156 paquetes de modelos Live2D Cubism (`.moc3`, `.model3.json`, `.physics3.json`, `.motion3.json` y atlas de texturas `.png`).
- **`04_Modelos_3D/`**: Mallas 3D en formato `.obj` de Personajes (cuerpo, rostro, ropa, peinado), Armas, Monstruos/Jefes, Muebles de dormitorio y NPCs, con texturas `.png`.
  - Incluye visor web interactivo en 3D: `Visor_Modelos_3D.html`.
- **`05_Ilustraciones_y_CGs/`**: 97 CGs de historia en resolución 2.5K, 1,099 ilustraciones de discos y 5,173 sprites 2D organizados por personaje.
  - Incluye visor web de historia: `Visor_CGs_Historia.html`.
  - Incluye visor interactivo de sprites: `Sprites_Personajes_2D/Visor_Sprites_2D.html`.
- **`06_Iconos_y_UI/`**: Iconos de habilidades (Skills/Ultimates), avatares, trajes, cartas de destino y objetos.
- **`07_Escenarios_3D/`**: Mallas 3D de entornos, mapas, mazmorras y ruinas.
- **`08_Base_de_Datos_y_Scripts/`**: Archivos de base de datos (`data.arcx`), lógica (`lua.arcx`) y biblioteca `.NET` (`Hotfix.dll`).
